\# Financial Model



\## Product Financial Data



Fields:



\- purchase\_price

\- sale\_price

\- supplier



Metrics:



\- Product Margin

\- Inventory Value



Formula:



Margin = Sale Price - Purchase Price



\---



\## Device Financial Data



Fields:



\- purchase\_price

\- current\_value

\- department\_owner

\- depreciation\_rate

\- retirement\_date



Metrics:



\- Asset Value

\- Department Costs

\- Depreciation



\---



\## Reporting Targets



Inventory Value



Total value of warehouse products.



\---



Asset Value



Total value of company assets.



\---



Department Asset Value



Asset value by department.



\---



Depreciation Report



Asset depreciation over time.



\---



Retired Assets



Disposed and retired equipment.
